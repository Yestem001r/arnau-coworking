# ARNAU Coworking — концепт сайта

Одностраничник для коворкинга ARNAU (Астана, ул. Туркестан 34).
Весь сайт — один файл `index.html`: стили и скрипты внутри, зависимостей и сборки нет.
Рядом только папка `photo/` с медиа.

## Как открыть

```bash
python3 -m http.server 8787
```

Видео в герое не проигрывается при открытии файла через `file://` — нужен именно сервер.

## Публикация на GitHub Pages

1. Запушить `index.html` и папку `photo/` в ветку `main`.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Сайт появится на `https://<логин>.github.io/<репозиторий>/`.

## Медиа

На странице **только настоящие снимки ARNAU** с карточки 2ГИС — пять штук, 920 КБ всего.
Сгенерированных картинок и видео нет ни одного кадра.

| Файл | Где |
|---|---|
| `hero.jpg` | первый экран, медленный наезд сделан CSS-трансформом (двигаются реальные пиксели) |
| `gal-1…4.jpg` | галерея «Атмосфера» |

Водяной знак 2ГИС срезан кропом, учтён EXIF-поворот, файлы пережаты под веб.
Права на снимки у клиента — перед публикацией оригиналы нужно забрать у него напрямую.

### Почему картинок мало и почему их нет в прайсе

Из девяти доступных снимков семь — почти одинаковые переговорные кабинки. По ним
**нельзя достоверно определить, какой это зал**: подписать кабинку как «конференц-зал
на 20 человек» значит подставить клиента под ошибку, которую он заметит первым.

Поэтому:
- прайс залов сделан типографическим, без фотографий;
- врезка «Режим работы» и блок мероприятий — текст и цифры, без картинок;
- подписи в галерее намеренно общие, без привязки к конкретному тарифу.

Как только клиент пришлёт съёмку по залам, картинки возвращаются в прайс —
разметка под это уже готова.

**Отдельно:** на 2ГИС есть снимок реального тренинга в их зале — лучший кадр для блока
мероприятий и сильное социальное доказательство. Я его не поставил: там узнаваемые лица
гостей. Если у клиента есть согласие на публикацию — кадр стоит добавить.

## Что нужно от клиента

Все места помечены в коде комментариями `TODO` и плашками «уточнить у клиента».

**Подтвердить:**
- Часы работы — на 2ГИС «ежедневно 09:00–24:00».
- Вместимость конференц-зала — в прайсе 2ГИС «до 20», в разделе «Инфо» — «до 50», в ТЗ было 15.
- Дневной тариф переговорной 10 000 ₸ — из рекламной строки 2ГИС, неясно, на какие кабинки.
- Цены на мероприятия и фотозону.
- Предоплата, еда с собой, скорость интернета, своя парковка, скидки на долгую аренду.

**Прислать:** нормальную фотосессию и картинку 1200×630 для шеринга.

**Вставить:** виджет карты 2ГИС вместо заглушки в блоке «Адрес» — инструкция в комментарии к коду.

## Что внутри

- Калькулятор: зал × часы × дата, с подсказкой, когда выгоднее взять день целиком.
- Две формы (бронь и мероприятие) показывают **живое превью сообщения**: текст собирается
  прямо по мере заполнения, незаполненные места подсвечены подсказками. Кнопка открывает
  WhatsApp по ссылке `wa.me` ровно с этим текстом — превью и отправка собираются одной
  функцией, поэтому разойтись не могут. Бэкенда нет, данные со страницы никуда не уходят.
- Кнопка в карточке зала и кнопка калькулятора подставляют зал и детали в форму брони.
- SEO: title/description под «коворкинг Астана», «переговорная на час», «зал для мероприятий Астана»,
  разметка JSON-LD `LocalBusiness` с адресом, телефоном, часами и прайс-каталогом.
- Проверено на 360, 768 и 1440 px: горизонтальной прокрутки нет, битых картинок нет, консоль чистая.
